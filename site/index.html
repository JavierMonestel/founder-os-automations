The operating system around a founder, automated.

Six importable n8n workflows, a Notion company OS you can build with one command, and the prompt library behind them. Built for an early-stage startup running a clinical line and a performance line on Notion, Linear, Attio, Grain, Slack and Claude.

Workflows

Each one is a plain n8n JSON file: Import from file, add four credentials (Anthropic, Notion, Linear, Slack), edit the Config node, done. Outward actions (emails, bookings, payments) stay human.

ROI calculator & process audit

Step one of automating anything: list the recurring work, estimate the time, and rank it by hours saved ÷ effort to automate. Edit the numbers. Everything stays in your browser.

Notion company OS

A single source of truth: objectives roll up key-result progress, meetings link to the decisions and follow-ups they created, and the follow-up radar reads Overdue every afternoon. One command builds it in any workspace:

NOTION_API_KEY=ntn_… python -m notion_os.bootstrap --parent <page-id> --sample-data

Prompt library

Every prompt is a contract: inputs, output format, what it must never do, and the checks used to test it.
